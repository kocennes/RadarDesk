# 4 Haftalik Ogrenme Plani

## Hafta 1: JavaScript Temelleri

- Degiskenler: `const`, `let`
- Veri tipleri: string, number, boolean, array, object
- Kosullar: `if`, `else`
- Donguler: `for`, `for...of`
- Fonksiyonlar

## Hafta 2: Modern JavaScript

- Arrow function
- Array metotlari: `map`, `filter`, `reduce`, `find`
- Object destructuring
- Template literal
- Module sistemi: `import`, `export`

## Hafta 3: TypeScript Temelleri

- Tip belirtme
- `type` ve `interface`
- Fonksiyon parametre/donus tipleri
- Union type
- Optional alanlar

## Hafta 4: Mini Proje

Konsolda calisan basit bir gorev listesi uygulamasi yap:

- Gorev ekleme
- Gorev listeleme
- Gorev tamamlandi isaretleme
- TypeScript ile tip guvenligi
