# Temel Komutlar

```bash
npm install
npm run js
npm run ts
npm run ts:check
npm run build
```

## Dosya anlamlari

- `package.json`: Proje komutlari ve paketleri.
- `tsconfig.json`: TypeScript ayarlari.
- `src/javascript`: JavaScript ders dosyalari.
- `src/typescript`: TypeScript ders dosyalari.
- `exercises`: Alistirmalar.
- `docs`: Notlar ve plan.
